## 1. 로고 스토리

온길의 이름 — **온(溫·全)**과 **길(道)** — 그리고 다섯 역할이 당사자를 향해 협업하는 구조를 하나의 곡선에 담았습니다. 직선이 아닌 하나의 흐르는 곡선이 다섯 가지 색을 순서대로 지나며, 마지막에 당사자를 상징하는 따뜻한 색 점에 도착합니다.

| 요소 | 의미 |
|---|---|
| **길(道)** | 직선이 아닌 하나의 흐르는 곡선 — 삶은 정해진 규격이 아니라 저마다 다르게 흘러가는 여정이라는 뜻 |
| **온(溫)** | 곡선 끝에 닿는 따뜻한 앰버색 점 — 모든 협업의 목적지는 결국 당사자의 온기 있는 하루 |
| **온(全)** | 다섯 색이 끊기지 않고 하나의 선으로 이어짐 — 역할은 나뉘어도 기록과 여정은 전체로서 하나임 |
| **다섯 역할** | 보호자·치료사·특수교사·사회복지사·활동지원사, 각자 고유색을 가지되 결국 한 곡선 위에 존재 |
| **당사자** | 곡선이 도착하는 마지막 지점 — 모든 협업의 시작이자 끝은 언제나 당사자 |

## 2. 로고 해부 (Anatomy)

로고는 6개의 지점(5개의 색 구간 + 1개의 도착점)으로 구성되며, 색상의 순서 자체가 "협업의 흐름"을 나타냅니다.

| 순서 | 구간 색상 | HEX | 역할 | 의미 |
|---|---|---|---|---|
| 1 | ● 짙은 브랜드 그린 | `#0F6E56` | 보호자 | 협업의 시작점 · 권한의 허브 |
| 2 | ● 레드 | `#E04545` | 치료사 | 치료계획과 회기의 연속성 |
| 3 | ● 블루 | `#4377C0` | 특수교사 | 배움과 관찰의 기록 |
| 4 | ● 틸 그린 | `#3EA673` | 사회복지사 | 목표와 전환의 설계 |
| 5 | ● 오렌지 | `#E8991E` | 활동지원사 | 일상 속 가장 가까운 손길 |
| 6 (도착점) | ● 앰버 | `#FAC775` | 당사자 | 모든 길이 도착하는 곳, 온기 |

**핵심 원칙**: 선은 끊기지 않고 색만 바뀌며 이어집니다. 이는 "직선적 협업"이 아니라 "한 사람에게 흘러 들어가는 하나의 여정"으로 읽히도록 의도된 것이며, 곡선이 당사자의 색(앰버)에서 멈추는 것도 "길이 당사자를 지나치지 않고 도착한다"는 의미를 담기 위한 설계입니다.

## 3. 로고 배리에이션 (Symbol · Combination · Wordmark)

모든 로고는 사용 맥락에 맞게 3가지 포맷으로 제공됩니다.

### A. 심볼 (Symbol)
텍스트 없이 단독으로 사용하는 마크입니다.
- **용도**: 앱 아이콘, 파비콘, 프로필 이미지 등 텍스트 없이 쓰는 모든 곳
- **배경**: 다크(primary-900) 배경 위 풀 컬러 사용을 기본으로 함

### B. 로고 + 명칭 (Combination)
심볼과 워드마크를 함께 쓰는 조합형입니다.
```
[심볼]
 온길
ONGIL
```
- **용도**: 명함, 웹사이트 헤더, 공문서 등 심볼과 워드마크를 병기하는 모든 곳
- **배치**: 심볼이 위, 워드마크(온길)가 중앙, 영문 표기(ONGIL)가 하단 소형 텍스트로 배치

### C. 명 (Wordmark)
글자만으로 브랜드를 표현하는 로고타입입니다.
```
온길
———
ONGIL
```
- **용도**: 본문 내 텍스트 언급, 좁은 배너, 워터마크
- **스타일**: "온"은 브랜드 그린, "길"은 다크 그린으로 대비를 주고, 앰버색 밑줄 포인트로 심볼의 도착점 색을 은유

## 4. 클리어스페이스 & 최소 크기

### 클리어스페이스 (여백)
로고 주변에는 항상 **심볼 높이의 1배 이상**에 해당하는 여백(X)을 확보해야 합니다. 다른 텍스트, 이미지, UI 요소가 이 여백 안으로 침범해서는 안 됩니다.

### 최소 크기

| 용도 | 최소 크기 | 비고 |
|---|---|---|
| 디지털 심볼 | 20px | 5개 곡선이 뭉개지지 않는 최소 기준 |
| 인쇄 심볼 | 10mm | 명함·굿즈 등 인쇄물 최소 기준 |
| 로고 + 명칭 | 가로 32mm | 워드마크 가독성 확보 기준 |
| 파비콘 전용 | 16px | 심볼만 단순화하여 사용 권장 |

## 6. 컬러 배리에이션

| 배리에이션 | 배경 | 설명 |
|---|---|---|
| 풀 컬러 (다크 배경) | Primary-900 | 기본형. 5색 협업 구조가 온전히 드러남 |
| 다크 배경 모노 | Primary-900 | 짙은 배경 위 단색(화이트, 투명도 단계 적용) 축소 버전 |
| 라이트 배경 모노 | 화이트/카드 배경 | 밝은 배경·인쇄물 단색(다크그린) 축소 버전 |
| 풀 컬러 (라이트 배경) | 화이트/카드 배경 | 화이트·라이트 배경 기본 사용 |

**사용 원칙**
- 가능하면 항상 풀 컬러 버전을 우선 사용한다 (5색 협업 구조가 핵심 메시지이므로)
- 저해상도·초소형 인쇄(10mm 이하) 등 색 구분이 어려운 경우에만 모노 버전을 사용한다
- 모노 버전 사용 시 배경 대비 최소 4.5:1을 확보한다

## 7. 잘못된 사용 (Incorrect Usage)

| ❌ 금지 사항 | 이유 |
|---|---|
| 임의로 색을 바꾼다 | 역할 컬러 체계가 훼손되어 "협업의 흐름"이라는 의미가 사라짐 |
| 회전하거나 기울인다 | 도착점(당사자)을 향하는 방향성이 왜곡됨 |
| 가로/세로 비율을 다르게 늘리거나 압축한다 | 원본 비율(1.2:1)이 깨져 곡선의 형태가 왜곡됨 |

**✅ 올바른 사용**
- 지정된 5가지 역할 컬러와 당사자 앰버색을 순서대로 그대로 사용한다
- 심볼은 항상 정방향(회전 없이)으로, 원본 비율(1.2:1)을 유지해 배치한다
- 충분한 여백을 확보하고, 배경과의 대비를 항상 확인한다

## 9. 다양한 활용 방안 (Applications)

### 9-1. 앱 아이콘 & 파비콘
- **iOS**: 둥근 사각형(Squircle), 배경 Primary-900, 심볼 여백은 아이콘 크기의 18% 이상
- **Android**: 원형, 동일한 배경·여백 규칙 적용
- **파비콘(16~32px)**: 심볼만 단순화하여 사용, 매우 작은 영역에서는 도착점(앰버) 대비를 살짝 높인 버전 허용
- **브라우저 탭**: 파비콘 + "온길" 텍스트 조합

### 9-2. 명함 (앞 · 뒤)
- **앞면**: 다크 배경(Primary-900), 심볼(화이트 모노) + 워드마크 + 슬로건("내 삶의 모든 길이 여기 있습니다")
- **뒷면**: 라이트 배경, 성명·직함·연락처 정보 + 우측 하단에 작은 심볼(다크 모노) 워터마크

### 9-3. 웹사이트 헤더
- 헤더 바: 화이트 배경, 좌측에 심볼(풀 컬러 소형) + 워드마크, 우측에 내비게이션 메뉴 + CTA 버튼(Primary-600)
- 히어로 섹션: 다크 배경 위 심볼을 대형·저투명도 워터마크로 배치, 헤드라인 카피 전경 배치

### 9-4. 모바일 앱 스플래시 화면
- 배경 항상 Primary-900, 심볼(풀 컬러)을 화면 중앙보다 살짝 위에 배치
- 하단에 워드마크 + 슬로건, 1.2~2초 후 자동 페이드아웃
- **접근성**: 모션 최소화(reduce-motion) 대응, 당사자 모드에서는 슬로건 생략 가능

### 9-5. 소셜미디어 프로필 이미지
| 형태 | 플랫폼 | 규칙 |
|---|---|---|
| 원형 | 인스타그램·페이스북·카카오채널 | 심볼을 프레임 65% 크기로 중앙 배치 |
| 둥근 사각형 | 유튜브 | 심볼 상하 여백을 좌우보다 살짝 넉넉하게 |
| 정사각형 | 브런치·블로그 등 | 배경에 미묘한 원형 그라디언트 허용 |

### 9-6. 공문서 · 보고서 표지
- 상단 헤더 바에 심볼(화이트) + 워드마크 고정 배치
- 본문 영역에 심볼을 옅게(투명도 80%+) 워터마크로 배치 가능
- 표지 제목은 항상 심볼보다 시각적 우선순위를 높게 배치

### 9-7. 이메일 시그니처
```
[심볼]  |  김온길
       Product Lead · 온길
       hello@ongil.example
       +82 10-0000-0000
       www.ongil.example
———————————————————————————
```

### 9-8. 뱃지 · 굿즈
- **핀뱃지·스티커**: 소형 굿즈는 심볼 단독 사용 권장, 테두리 색은 앰버(당사자색)로 통일해 시리즈감 부여
- **직물(에코백 등)**: 인쇄 시 다크 모노 버전 우선 사용
- **협업 인증 스탬프**: 기관 간 공식 협약서 등에는 다크 모노 버전 + "Official Partner" 문구 병기

## 10. 부록 — SVG 소스

로고 심볼(풀 컬러)의 원본 벡터 소스입니다. `viewBox="0 0 120 100"` 기준이며, 비율(1.2:1)을 유지한 채 자유롭게 리사이즈할 수 있습니다.

```svg
<svg width="600" height="500" viewBox="0 0 120 100" xmlns="http://www.w3.org/2000/svg">
  <path d="M 110.6 75 Q 69.75 93.25 21 90.2" fill="none" stroke="#0F6E56" stroke-width="7" stroke-linecap="round"/>
  <path d="M 21 90.2 Q 7 57 10.2 17" fill="none" stroke="#E04545" stroke-width="7" stroke-linecap="round"/>
  <path d="M 10.2 17 Q 35.75 7.25 67 10.6" fill="none" stroke="#4377C0" stroke-width="7" stroke-linecap="round"/>
  <path d="M 67 10.6 Q 72.5 28.5 69 51" fill="none" stroke="#3EA673" stroke-width="7" stroke-linecap="round"/>
  <path d="M 69 51 Q 58.75 52.3 45 48.7" fill="none" stroke="#E8991E" stroke-width="7" stroke-linecap="round"/>
  <circle cx="45" cy="48.7" r="14" fill="#FAC775"/>
</svg>
```

**모노 버전 사용 시**: 위 소스에서 각 `stroke` 값과 `circle`의 `fill` 값을 다음으로 일괄 치환합니다.
- 다크 배경용(화이트 모노): 모든 색상 → `#FFFFFF` (구간별 opacity 0.55~1.0 단계 적용 권장)
- 라이트 배경용(다크 모노): 모든 색상 → `#064E3B` (동일하게 opacity 단계 적용 권장)
