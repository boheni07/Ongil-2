## 2. 화면 유형 정의 (Screen Types)

| 코드 | 유형 | 설명 | 대표 화면 |
|------|------|------|---------|
| ST-01 | Hub / Dashboard | 요약 카드 + 빠른 진입점 | G-01, S-01, W-01 |
| ST-02 | List | 목록 + 필터/검색 | 기록 목록, 알림 목록 |
| ST-03 | Detail | 상세 읽기 전용 | 기록 상세, 인수인계 상세 |
| ST-04 | Form — Single | 단일 페이지 폼 | 관찰기록, 회기일지 |
| ST-05 | Form — Multi-step | 단계 분할 위자드 | IEP(6단계), 일지(5단계), 권한(4단계) |
| ST-06 | Timeline | 시간순 피드 + 도메인 레인 | G-10, T-20, W-20, TH-20 |
| ST-07 | Matrix / Table | 행·열 표 + 인라인 필터 | 권한 매트릭스, 접근 로그 |
| ST-08 | Icon Selector | 대형 아이콘 선택 (72×72px) | 당사자 자기표현 P-02 |
| ST-09 | Auth / Onboarding | 인증·역할 선택·최초 설정 | 로그인, 회원가입 |
| ST-10 | Modal / Bottom Sheet | 오버레이 확인·간단 입력 | 삭제 확인, 날짜 선택 |
| ST-11 | Settings | 설정 항목 + 토글 | 알림 설정, 접근성 |

### 3-9. 생애주기 단계 배지·필터 적용 화면

`life_stage`(아동기/청소년 전환기/성년기, PRD §3-1) 계산값을 시각적으로 노출하는 화면 목록. 컴포넌트 사양은 `03-uiux.md` §6-6 `StageBadge` 참조.

| 화면 ID | 화면명 | 적용 방식 |
|--------|--------|---------|
| G-01 | 대시보드 (PersonCard) | 카드 상단에 StageBadge 표시 |
| G-10 | 타임라인 | 헤더에 StageBadge + 레인뷰에 단계 전환 시점 세로 구분선, 상단 필터에 단계별 토글 추가 |
| G-30 | 권한 관리 | 성년기 진입 시 "본인 동의 이관 완료" 안내 배너 |
| P-01 | 오늘 기록 홈 | 헤더에 StageBadge(당사자 본인에게는 쉬운 문구로 대체 표시) |
| T-01 | 담당 학생 카드 목록 | 카드에 StageBadge — `youth` 이상만 "전환계획 진행중" 서브텍스트 노출 |
| T-13 | IEP 작성 위자드 | 5/6 전환 계획 스텝 잠금해제 조건 = `life_stage != 'child'` |
| T-20 | 타임라인 (교육) | G-10과 동일 필터 패턴 |
| W-01 | 담당 당사자 현황 홈 | 카드에 StageBadge — `adult` 대상만 "성인 서비스 전환 필요" 배지 우선 노출 |
| W-16 | 전환계획 작성 | 진입 가드: `life_stage == 'child'`인 당사자는 작성 불가 안내로 대체 |

### 3-10. 기록 확인(Confirmation) 배지·화면 적용 지점

"승인"이 아니라 "확인" 절차(PRD §3-4, ERD §4-6)가 노출되는 화면 목록. 컴포넌트 사양은 `03-uiux.md` §6-7 `ConfirmBadge` 참조.

| 화면 ID | 화면명 | 적용 방식 |
|--------|--------|---------|
| G-01 | 대시보드 | "확인 대기 기록 N건" 요약 카드 신규 (기존 최근기록/권한현황/알림 카드 옆) |
| G-20 | 기록 관리 목록 | 확인 대기 항목에 `ConfirmBadge`(미확인) 칩 표시, 목록 정렬 시 미확인 우선 |
| G-20D | 기록 상세 | `requires_confirmation=true`이면 상단에 "확인했습니다" CTA 노출, 확인 후 확인자·확인일시 표시로 전환 |
| P-10 | 기록 보기 (당사자) | 성년기(`adult`)에 한해 본인이 확인 주체 — 쉬운 언어로 "이 기록을 봤어요" CTA |
| T-13, W-13, TH-13 | 각 위자드 6/6·5/6·5/6 확인 단계 | 제출 시 "확인 요청 대상: {보호자명 또는 본인}" 안내 문구 추가 |

## 4. 내비게이션 패턴

### 4-1. 반응형 웹 — Sidebar + Split Pane

```
┌──────────────────────────────────────────────────────────────┐
│ GLOBAL HEADER (56px)  [Logo] [당사자선택] [🔔] [프로필]          │
├──────────┬───────────────────────────────────────────────────┤
│          │  브레드크럼 (Depth 3+)                               │
│ SIDEBAR  ├────────────────────────┬──────────────────────────┤
│ (220px)  │  LIST PANEL            │  DETAIL PANEL             │
│          │  (40%, D3)             │  (60%, D3)                │
│ D1 메뉴  │                        │                           │
│ 아이콘+  │                        │                           │
│ 레이블   │                        │                           │
└──────────┴────────────────────────┴──────────────────────────┘
```

| Depth | 웹 레이아웃 | 비고 |
|-------|-----------|------|
| D1 | Sidebar + Full Content | Hub, Timeline |
| D2 | Sidebar + Sub-tab + Content | 목록/필터 |
| D3 | Sidebar + List + Detail (Split) | 1024px+ |
| D4 | Sidebar + Form (Centered, max-w 720px) | 입력 |
| D5 | Sidebar + Form Step N/N | 다단계 위자드 |

### 4-2. 모바일 앱 — Bottom Tab + Stack

```
┌────────────────────────┐
│  STATUS BAR             │
├────────────────────────┤
│  NAV BAR ← 타이틀 [액션] │  ← D2+ 스택
├────────────────────────┤
│                        │
│  CONTENT               │
│  (Stack Screen)        │
│                        │
├────────────────────────┤
│  BOTTOM TAB BAR        │  ← D1 (플로우 중 숨김)
│  [탭1] [탭2] [탭3]     │
└────────────────────────┘
```
